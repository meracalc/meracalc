This repository contains the `app-ads.txt` file for AdMob verification in Google Play Console.

## How to Use

1. Go to [Google Play Console](https://play.google.com/console)
2. Select your app
3. Navigate to: **Apps > App content > Ads**
4. Find the field labeled **"app-ads.txt URL"**
5. Paste this URL:
   ```
   https://raw.githubusercontent.com/meracalc/meracalc/main/app-ads.txt
   ```
6. Click **Verify**

Google will automatically verify your AdMob publisher ID and your app will be whitelisted for AdMob ads.
